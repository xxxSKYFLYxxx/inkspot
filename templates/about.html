О платформе InkSpot

InkSpot – учебный проект: лёгкая платформа для блогинга и публикации контента, разработанная в рамках курсовой работы.

Возможности

  • Регистрация и авторизация пользователей.
  • Создание, редактирование и удаление статей с обложкой.
  • Категории, поиск, постраничная навигация.
  • Лайки и комментарии.
  • Личный профиль с аватаром и описанием.

Технологии

Python 3 Flask SQLAlchemy SQLite HTML5 CSS3 JavaScript Bootstrap 5

Архитектура

Приложение построено по схеме MTV (Model–Template–View): модели описаны через SQLAlchemy, представления реализуются маршрутами Flask, шаблоны – на Jinja2. Хранение данных – SQLite (для разработки) с возможностью перехода на PostgreSQL.
